# TRUCO SURVIVAL

Prototipo mobile-first de un juego survival inspirado en la jerarquía de cartas del Truco argentino.

Cada jugador comienza con 20 naipes. El rival juega una carta y el usuario toca la suya para darla vuelta. La carta ganadora vuelve a su mazo y captura la perdedora; desde el duelo 40, cada victoria transfiere hasta tres cartas para acelerar el cierre de la partida.

## Ejecutar

Es un sitio estático sin dependencias. Abrí `index.html` en un navegador o serví la carpeta raíz con cualquier servidor HTTP.

## Assets

Los naipes españoles están basados en la baraja de Basquetteur disponible en Wikimedia Commons y se distribuyen bajo licencia CC BY-SA 3.0. El juego incluye una representación con emojis como respaldo cuando falla un asset.
